## Fixes, Nov 5 (decisions from Larry)

Measured in the app at 1280 after the changes: search icon 12px in, search text 32px in, tab icon-to-label 4px, keycap radius 2px. Panel corner shows box border, 1px paper, then the 5px ink shadow.

- Button: 8px padding + the label frame's 2px; code 1px border + 9px (text) and 7px before a leading icon.
- Segment / type tabs: 4px icon gap (margin-right: calc(4px - 1ch)).
- Field / Search Field / filters: 4px icon gap; text 32px in (31 + border); keycap 4px from the text (padding-right 57, 81 with clear).
- App Header: keeps the page gutter (code-owned).
- Choice checkbox: stays square in code; Figma to drop its 2px radius.
- Keyboard Hint: 2px radius in code.
- Shadow/Hard: 1px 1px 0 paper/photo, then 5px 5px 0 ink.
- color/border/inverse: added; used by the profile panel's fold button and the quick view's close.

## Borders excluded from layout (Nov 5, later)
